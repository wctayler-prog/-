電腦故障維修自己DIY檢查 電腦維修： 基本概念：一般電腦可分為下列四個部分 主機部份：主機板、CPU、記憶體、電源供應器 介面卡部份：螢幕卡、音效卡、網路卡 磁碟機部份：SSD硬碟、一般硬碟 週邊設備部份：螢幕、鍵盤、滑鼠、印表機、喇叭、麥克風

電腦開機流程：了解它，電腦維修才有概念 1.開啟電源 2.螢幕出現BIOS測試畫面，並進行POST自我測試 3.沒硬碟會出現Reboot and Select proper Boot device or Insert Boot Media in Selected Boot device and press a key 4.載入作業系統：POST沒問題先出現系統架構表，然後載入作業系統 5.執行作業系統

電腦維修流程： 1.開啟電源 (請確實檢查各接頭是否正確接好) 2.是否出現螢幕畫面 (否：主機故障) 依實務的經驗，不見得一定是主機故障。 它有可能是螢幕的故障。若是牽涉到主機的部份，最常見的故障， 依序是：記憶體、顯示卡、CPU。 3.螢幕是否出現錯誤訊息 (是：螢幕錯誤訊息診斷) 4.是否順利載入作業系統 (否：作業系統錯誤) 5.介面卡功能是否正常 (否：介面卡故障) 6.週邊設備功能是否正常 (否：週邊設備故障)

主機維修：(注意主機板是否太髒及BIOS設定是否正確，可移開電池再放回，使恢復出廠值) 先檢查各接頭是否確實接好, ▼ 打開主機外殼，拔掉所有介面卡及排線 ▽ 主機板壞掉通常沒有嗶聲，除非PC 主機板speaker壞掉，或插speaker的腳位壞掉， 或者主機板上沒有speaker腳位可以插，這時可以裸測檢查主機板有無壞掉，也可以用 測試卡檢查主機板有無壞掉，只是本人習慣用裸測測主機板有無壞掉。 ▼ 若有連續不斷的嗶嗶聲：記憶體故障,拔起記憶體,記憶體金手指以橡皮擦,擦拭氧化部分,再重新插回去(適用於AWARD BIOS 現在大部分的BIOS) 若有一長音嗶聲：顯示卡故障,拔起顯示卡,主機板的插槽用長毛刷清一清,記憶體金手指以橡皮擦,擦拭氧化部分,再重新插回去,並檢視顯示卡風散是否運作(適用於AWARD BIOS 現在大部分的BIOS) ▼ 螢幕錯誤訊息維修：(建議先進安全模式後，再重新啟動看看，如果還不行往下看)

1.BIOS啟動後錯誤訊息： BIOS ROM checksum error-System halted：表示BIOS ROM的資料錯誤--找原廠更新BIOS CMOS battery failed：換新電池即可 CMOS checksum error-Ddfaults loaded：選LOAD SETUP DEFAULTS即可 Keyboard error or No keyboard present：確實接好，別台試試 Memory test fail：重插(一次試一支) Primary master hard disk fail：BIOS中的設定是否正確，排線電源是接好，MASTER/SLAVE的JUMPER

2.系統組態表出現後出現錯誤訊息： NO partition bootable：未做FDISK NO rom basic-- press a key to reboot：未設開機分割區 Missing operation system：未做format Non-system disk or disk error：找不到開機系統檔，以開機片開機後 sys c: Bad or missing command interpeter：command.com不見或損壞，拷回 Invalid system disk：BIOS太老舊不支援LBA模式的硬碟，原廠更新BIOS Cannot load command,system halted：command.com損壞或版本不對 Disk boot failure：硬碟控制卡故障或開機磁區壞掉，可拿到別台試試，卡壞換卡，否則應為MBR 或DBR 故障(所以平常應備份)
